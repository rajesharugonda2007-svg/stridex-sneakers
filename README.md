## 🎯 Project Overview
**StrideX** is an athletic footwear brand website showcasing modern streetwear sneakers, running shoes, and training gear. The website emphasizes visual hierarchy, semantic HTML5 structure, responsive layout design, and smooth hover micro-interactions.

---

## ✨ Features & Highlights

- **Semantic HTML5 Architecture:** Built using proper semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) adhering to web accessibility and SEO best practices.
- **Modern CSS3 Design Tokens:** Uses CSS custom properties (`:root` variables) for consistent design palettes, shadows, and transitions.
- **Responsive Layout:**
  - **CSS Grid** for multi-column product showcases and category tiles.
  - **Flexbox** for navigation, hero banners, and inline elements.
  - Comprehensive **Media Queries** adapting seamlessly across desktop, tablet, and mobile screens.
- **E-Commerce Visual Elements:**
  - Status Badges (`BESTSELLER`, `NEW ARRIVAL`, `-25% OFF`, `TRENDING`).
  - Customer Star Ratings & Price Strikethroughs (`₹3,499` ~~₹4,999~~).
  - Trust Badges (Free Delivery, 7-Day Returns, Secure Checkout).
  - Discount Coupon Banner (`STRIDE30`) and Newsletter Subscription form.
- **Icons & Typography:** Powered by **Font Awesome 6** and Google Fonts (**Plus Jakarta Sans**).
